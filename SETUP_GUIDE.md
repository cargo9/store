## 📋 Шаг 1: Установить PostgreSQL

### Windows:
1. Скачать: https://www.postgresql.org/download/windows/
2. Запустить установщик
3. **ВАЖНО:** Запомнить пароль для пользователя `postgres`
4. Порт по умолчанию: 5432

### Проверить установку:
```bash
psql --version
```

---

## 📋 Шаг 2: Создать базу данных

Открыть командную строку и выполнить:

```bash
psql -U postgres
```

Ввести пароль, который вы установили при установке PostgreSQL.

Затем выполнить:
```sql
CREATE DATABASE gomerchstore;
\q
```

## 🔍 Как это работает

### Фронтенд (React)
- Работает на порту 3000
- Отправляет запросы к бэкенду
- Хранит JWT токен в localStorage

### Бэкенд (Node.js + Express)
- Работает на порту 5000
- Обрабатывает запросы от фронтенда
- Проверяет пароли, создает токены
- Общается с базой данных

### База данных (PostgreSQL)
- Хранит всех пользователей
- Пароли зашифрованы (bcrypt)
- Данные не теряются при перезагрузке

### Поток регистрации:
1. Пользователь вводит данные на фронтенде
2. Фронтенд отправляет POST запрос на `/api/auth/register`
3. Бэкенд проверяет данные
4. Бэкенд хэширует пароль
5. Бэкенд сохраняет в PostgreSQL
6. Бэкенд создает JWT токен
7. Фронтенд получает токен и сохраняет
8. Пользователь залогинен!

## 🐛 Troubleshooting

**Ошибка: "ECONNREFUSED" при запуске фронтенда**
- Убедитесь, что бэкенд запущен (порт 5000)

**Ошибка: "password authentication failed"**
- Проверьте пароль в `server\.env`

**Ошибка: "Port 5000 is already in use"**
- Закройте другие программы на порту 5000
- Или измените PORT в `server\.env`

**Ошибка: "database does not exist"**
- Создайте базу данных (Шаг 2)
